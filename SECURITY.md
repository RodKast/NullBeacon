# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| v0.1.x (latest) | ✅ |
| < v0.1.0 | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in NullBeacon, please report it responsibly.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Instead, send an email to: **chrisapo23@outlook.com**

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

You will receive a response within **72 hours**. If the vulnerability is confirmed, a fix will be released as soon as possible and you will be credited in the changelog.

## Scope

NullBeacon is a security research tool. Vulnerabilities that are in scope:

- Memory safety issues in the teamserver or agent
- Authentication bypass in the teamserver
- Insecure default configurations
- Dependency vulnerabilities

## Disclaimer

NullBeacon is built for **authorized security research, CTF competitions, and home lab use only**. The maintainers are not responsible for misuse of this tool.
